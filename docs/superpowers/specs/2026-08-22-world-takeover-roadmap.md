# Master Roadmap: Stable Village → World-Ready Protocol

**Status: APPROVED by owner 2026-08-22**

Mission: OpenBoard must survive tests no designer hand-picked, become
human-playable, then become a publicly verifiable protocol on Cardano.

## Arc I — Prove the society

| Stage | Build | Gate |
|---|---|---n| --- |
| 1 Democracy in the loop | political bots propose/vote self-interestedly; economy re-tunes itself; faction attack | governance-active worlds stable multi-seed; ≥1 proven self-correction; capture fails visibly |
| 2 Adversary lab | systematic action-space search + API fuzzing; find→fix→regression-test loop | well-resourced attacker cannot break invariants/welfare floor |
| 3 Competition & capital | 2nd producer per sector, coop entry/exit, toolsmith chain; retire capital_refresh | markets clear w/ ≥2 competitors; economy builds own machines |
| 4 Breadth | all 39 goods produced; needs met by production not endowment | zero unmet with endowments OFF |
| 5 Shocks & growth | seeded disasters, population growth, coop founding, recipe innovation | survives shock battery, recovers within N ticks |
| 6 Robustness at scale | parameter sweeps (stable region), 100-1000 citizens, perf | stability region charted; 1k citizens in budget |

## Arc II — Make it human

| Stage | Build | Gate |
|---|---|---|
| 7 Citizen Seat + Break the System | citizen-chair UI, multiplayer, first human game | humans play; found exploits fixed; world survives |

## Arc III — Take it public

| Stage | Build | Gate |
|---|---|---|
| 8 Chain + community | testnet anchoring → mainnet, public runs, protocol docs, Catalyst proposal | anyone verifies history from chain; external participants |

Parallel: continuous polish (genesis alert noise, Gini card scale),
dashboard grows per stage.

Order rationale: each stage de-risks the next; on-chain anchoring of an
unproven economy would be anchoring a failure.
