# Priority 2: Player Behavior Study (2026-09-12)

## Purpose
Answer STUDY_PLAN's three Priority-2 questions using controlled 1000-citizen probes.

## Experiments

| Scenario | Parameter Hack | Measurement |
|---|---|---|
| **Skills (Training Bottleneck)** | `params['skills'] = {'enabled': True, 'hours_per_level': 100, 'max_level': 5, 'output_bonus_bp': 500, 'wage_bonus_bp': 300}` **initially inject** each worker with `state.skills[key] = 5000` at t=2. | Compare unmet needs and machine inventory vs control. If production spikes too fast, machine bids clear at prices coops can't afford → shortages. |
| **Voting (Short-Sighted Tax)** | Force a `RULE_CHANGE` proposal at t=10 that sets `wealth_tax.rate_bp = 2000` (20%/tick) while reducing `surplus_spending.dividend_share_bp = 1000`. Run with politics bots enabled. | Track `unmet_needs` (especially essentials) and coop treasury depth. If coops go bankrupt before wealth tax accrues → tax kills factories. |
| **Crisis Mode** | Declare a crisis at t=2 via `state.crisis = { ... }` (bypass ratification) and enforce luxury stop in crisis phase. | Compare food supply (bread production ticks) and unmet food needs vs control. Emergency rule should protect essentials, not collapse them. |

## Metrics
- **Unmet needs (essential):** primary stability signal.
- **Coop treasury depth:** liquidity risk.
- **Machine inventory:** capital stock (bottleneck indicator).
- **Gini/wealth concentration:** secondary.

## Data Location
`sweeps/p2/` (one JSON per seed/scenario, 650 ticks each).
