# Multi-Agent System Audit — 2026-09-20 (RC1 freeze review)

**Method:** six parallel reviewer agents, each with a distinct lens (economic core, governance red-team, game layer, spec-vs-implementation, code quality, game design), read-only, citing file:line. Four completed with 46 findings (8 critical); two (spec-drift, code-quality) initially stalled and were restarted by the founder; both returned and their findings are recorded in the tracker as the S-series (spec-drift, S1-S8) and E-series (code-quality, E1/E5/E7/E9-E12) — see AUDIT_FIXES.md. Every finding below carries the synthesizer's verdict: **CONFIRMED** (read the cited code, real as described), **PROBE** (plausible, needs a small test before fixing), or **DECIDE** (works as coded, but the design choice itself is questionable).

**Freeze status:** no code changed. This document is the input to the founder's fix decision.

## A. GOVERNANCE CAPTURE (the most important theme)

The red-team found **compounding paths to minority rule** — each alone is bad; together they mean the republic we shipped can be captured by ~10% of the population.

| # | Finding | Verdict | Fix sketch |
|---|---|---|---|
| A1 | **CRISIS_VOTE has no one-vote-per-citizen check** — one citizen can submit unlimited crisis votes in one tick and single-handedly ratify any crisis (unlocks emergency powers: input priority suspended, research 100% redirected) | **CONFIRMED** — crisis ratification was only ever tested pre-ratified (`source="vote"`), so the in-crisis vote path never got real scrutiny | track voters per crisis declaration in state; reject repeat senders |
| A2 | **Structural 60% tier is computed over CAST weight with only 10% quorum** — strategic abstention shrinks the denominator; 10 colluders in 100 pass ANY structural change (the constitutional tier got this right with an all-citizen denominator; the structural tier didn't) | **CONFIRMED** — the math is exactly right | structural bar over ALL-citizen weight (citizens × token_bp) |
| A3 | **Delegation mirroring multiplies one actor's weight** — a delegate's 10,000bp 'for' is mirrored by EVERY follower: bloc weight = (1+F)×10,000; combined with A2, one popular citizen alone passes structural changes; delegations read at tally-time, so last-second sweeps flip outcomes | **CONFIRMED** — per-follower semantics don't bound aggregate blocs | cap mirrored weight per delegate; snapshot delegations at proposal-open |
| A4 | **Trust entrenchment machine** — unknown politicians start at trust 100 → persuasion dice ~99% yes; +5 trust for ANY passed proposal; no engine-side proposal rate limit; the die (tick:pid:who) is precomputable so a proposer can pick lucky opening ticks | **CONFIRMED** — the no-op guard only blocks exact-equality; micro-delta ping-pong is legal | default trust ~50; reward trust on proposal OUTCOME (post-trial), not passage; rate-limit proposals per cycle; seed the die on proposal content hash |
| A5 | **Structural whitelist too narrow** — `surplus_spending.dividend_share_bp` (up to 10,000bp = drain the whole surplus pool to holders) needs only simple majority; salami slicing (+500bp/month) never triggers any tier | **CONFIRMED** — `_STRUCTURAL_TOP_KEYS` omits surplus_spending/loans/oversight/scarcity | add the economically decisive keys; or classify by measured impact (pool-share delta) |
| A6 | **Auto-ratified crisis is a one-death kill-switch**, kind always 'pandemic', research 100% → 'health' even during a famine; an adversary engineers one death and weaponizes 600 ticks of emergency powers | **CONFIRMED as a DECIDE issue** — this came from the founder directive (crises auto-balance); the founder should re-decide: severity threshold + correct crisis kind, or keep as-is knowing the attack | severity requirement + kind mapping |
| A7 | Whistleblower bounty rotation: colluders rotate the villain role, harvest 500cr bounties from the pool | **PROBE** — needs the EV check (is the oversight penalty smaller than the bounty?) | bounty on enforced remedy; per-reporter caps |
| A8 | Vote-token attention race: bots dump tokens on the FIRST open proposal → decoys consume the electorate before the real vote | **CONFIRMED** (matches observed bot behavior) | don't open proposals in another's final tick; or prorate default-votes |
| A9 | Rollback trial window lets simple majorities cheaply revert structural changes | **CONFIRMED**, LOW | structural rollbacks keep the structural tier |

**Synthesis:** A1+A2+A3 compound — fix the trio together as one governance-hardening package. A4/A5 follow. A6 is a founder decision, not a bug.

## B. ECONOMIC ENGINE

| # | Finding | Verdict | Fix sketch |
|---|---|---|---|
| B1 | **Serial loan default drains the Society Pool without limit** — a defaulted loan doesn't block new loans; the record is overwritten (principal was a permanent pool→balance transfer; default freezes it; nothing claws it back). | B2 | **capital_rent 20× overcharge under durable_capital** — rent charges full machine value per RUN while durability spreads real wear over 20 runs; double depreciation | **PROBE** — depends on which params the live defaults use | rent on actual consumption (amortized), or skip rent for durables |
| B3 | **capital_wear + demand signals (recent_sales, unserved_bids) live outside the state hash and clone()** — operator-editable capital/demand without breaking the verifiable hash; replay cloning incomplete | **CONFIRMED** — matters for the tamper-evidence thesis | include in snapshot_dict; complete clone() |
| B4 | **capital_refresh retires money at stale credit-era book values** (machines priced 1,500 vs ~16,000 market) → fund hoards, refresh under-draws | **PROBE** | price refresh from live baselines, scale by units_per_credit |
| B5 | shocks/demographics/wage_debt_repay are read by the engine but rejected by ruleset validation — contradicts "everything votable" | **CONFIRMED**, MEDIUM | add to OPTIONAL_PARAMS with validators |

## E. WHAT THE AUDIT MEANS (synthesizer's assessment)

1. **The engine's conservation core is genuinely solid** — the reviewer traced every flow and found exactly one drain (B1) and one off-ledger state issue (B3). The byte-replay + hash-chain discipline held up under adversarial review.
2. **The democracy is capture-prone in compounding ways** — this is the single most important finding of the audit. The republic is the product, and A1-A5 mean a determined minority (or one popular delegate) can rewrite the rules. All fixes are small and local; none touch the engine's core loop.
3. **The game layer is honest but single-player-shaped** — the multiplayer promise needs auth + per-player state before it's real.
4. **The game doesn't tell its story yet** — the highest-leverage, lowest-cost fixes are D1/D5/D3: say the mission, render proposals in plain language, make the republic default.
5. **The pattern from the retrospective repeats:** the persuasion-whitelist bug predicted A5 (scattered whitelists), the round-attribution bug predicted C3 (client-trusted fields). The test standards in TESTING_RETROSPECTIVE.md §7 exist because of exactly these bug classes — the audit found their siblings.
